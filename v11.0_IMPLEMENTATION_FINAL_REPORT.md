## CRITICAL FIX: Nested Arrays

**Problem:** Firestore rejected `actionsData.layers[].shapes` because shapes were nested arrays (e.g. `[[{x,y}, {x,y}]]`) causing:
```
FirebaseError: Function DocumentReference.update() called with invalid data. Nested arrays are not supported
```

**Solution:** Deep sanitization before save and proper reconstitution on load:
- Serialize: `JSON.stringify` nested arrays (shapes) before writing to Firestore
- Deserialize: `JSON.parse` shapes strings after reading from Firestore

**Implementation (highlights in `firebase-data.js`)**:
- `sanitizeNestedArrays(value)`: recursiva que converte arrays que contêm arrays em strings JSON
- `serializeFloorsMap(...)` agora aceita `Map` OU `Object`, converte zonas e aplica sanitização a `actionsData`
- `deserializeNestedStrings(value)`: recursiva que parseia strings JSON que representam arrays
- `save/create` funções removem ruído de `collectAllData()` (`project`, `metadata`, `legacyInputs`) antes de gravar

**Key code lines**:
```javascript
// In serializeFloorsMap - stringify nested arrays (e.g. shapes)
result.actionsData = sanitizeNestedArrays(floor.actionsData);

// In deserializeFloorsArray - parse stringified arrays back
deserializedActionsData = deserializeNestedStrings(floor.actionsData);
```
